# 鸟的SQL辅助工具 🐦

纯 HTML 单文件的日常 SQL 辅助小工具箱，双击浏览器打开即用，**无需任何环境、数据全部本地处理**。

文件：`hue-id-formatter.html`

## 功能一览（6 个 Tab）

### 🔑 ID String 转换
粘贴 ID 列表（支持换行/逗号/空格/分号混合分隔，自动剥离已有引号），实时转成 `'id1','id2',...` 格式，用于 Hue 变量或 SQL `IN (...)`。
- 可选：单/双引号、括号包裹、去重、数字排序、仅保留纯数字
- 只有一个 ID 时自动不带逗号；一键复制

### ⏱️ Unix 时间戳互转
- 时间戳 → 日期：自动识别 10 位秒 / 13 位毫秒 / 16 位微秒，输出秒、毫秒、北京时间、UTC、ISO 8601
- 日期 → 时间戳：按北京时间（UTC+8）解析，输出 10 位秒 + 13 位毫秒

### 🗄️ 时间戳 SQL 转换
时间戳字段转日期/时间的 SQL 表达式，**Impala / MySQL 双方言**。
- 粒度：日 / 小时 / 分钟 / 周 / 月 / 年
- 可选东八区转换（+28800）、自定义变量名与别名
- 每次输出 3 种写法：推荐写法、备选写法（substr/date 简化版）、另一方言对照，各自一键复制

### 🗓️ 时间分区筛选
动态时间分区/过滤条件快速生成，同样双方言、多写法。
- 快捷区间：昨日 / 近 7 / 30 / 60 / 90 天 / 30~90 日前，起止偏移天数可自由改
- 输出类型：字符串日期（yyyyMMdd / yyyy-MM-dd / 自定义格式）或 Unix 时间戳（毫秒 ×1000 / 秒）
- 字段名可指定可留空；区间语义左闭右开；结束边界可选 NOW()
- 单日区间额外给出等值 `=` 写法（分区裁剪最友好）

### 📋 表头字段生成器
给 AI 提 SQL 需求前的指标表头字段清单生成，减少重复输入。
- 五层勾选：时间维度（天/week_start/月/小时）→ 统计实体（用户/主播/公会/房间）→ 行为×指标（活跃/进房/送礼/收礼/充值 × UV/PV）→ 输出模式（宽表 / Type 分类）→ 口径与比例
- 时长指标：在房时长、开播时长；新老客拆分 `user_type`；进房率、进房送礼率、付费转化率
- 结果为 chip 卡片，可逐个删减；默认带中文注释，可切纯清单
- 勾选状态本地记忆；内置 4 个预设组合；支持追加自定义字段

### 🔗 连表框架生成器
粘贴 `SHOW CREATE TABLE` 结果，自动解析字段/分区，一键生成 JOIN 查询框架。
- 支持**主表 + 多副表**，Impala / MySQL 双方言
- 自动识别库名表名、生成语义别名（users→u，冲突自动升级），别名可改
- **关联字段建议**：同名/词根匹配按置信度排序，点击即填充 ON 条件；类型不兼容自动标 ⚠️
- JOIN 模式内置风险提示（INNER 丢行 / LEFT fanout 膨胀 / FULL OUTER 的 MySQL 兼容性），选 FULL OUTER + MySQL 自动生成 UNION 模拟写法
- 自动补分区过滤条件；解析字段全量进 SELECT，chip 卡片逐个删减
- 附赠关联键唯一性自检 SQL（提前发现会撑爆行数的一对多关联）
- 只填表名不贴 DDL 也能生成纯框架

## 使用

浏览器直接打开 `hue-id-formatter.html` 即可，所有数据仅在你的浏览器本地处理，不发起任何网络请求。
